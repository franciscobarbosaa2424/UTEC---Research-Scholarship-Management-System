**SECU – Research Scholarship Management System**

Collaborative academic project developed at UTEC to manage research scholarship applications and evaluations.

- Developed business logic and data persistence using Java, JDBC and PostgreSQL.
- Applied DAO, Factory, Singleton and Proxy design patterns.
- Implemented database transactions, input validation and email notifications.
- Collaborated on software development, functional testing and version control using Git.

**Technologies:** Java, PostgreSQL, JDBC, SQL, JavaMail, Git.
